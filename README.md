# Block Matrices and Preconditioner for Deal.II using PSCToolkit

Test of block matrices and preconditioners using Deal.II and PSCToolkit. 

To download the code, run:

```bash
git clone --recurse-submodules git@github.com:psctoolkit/dealii-blocks.git
```
This clones the examples along with the compatible commits for PSCToolkit and Deal.II.

## Configuring and installing on a Laptop with spack

The [`configure-laptop`](./configure-laptop/) folder contains example shell scripts 
to configure and compile the PSCToolkit ([PSBLAS](https://github.com/sfilippone/psblas3/) 
and [AMG4PSBLAS](https://github.com/sfilippone/amg4psblas/)) 
alongside [Deal.II](https://github.com/dealii/dealii) in a unified workflow. 

After updating the environment module names (e.g., those generated by Spack) 
in [`environment_manual.sh`](./configure-laptop/environment_manual.sh), 
run the following commands:

```bash
cd psblas3
sh ../configure-laptop/psb_config_dealii.sh
make -j8

cd ../amg4psblas
sh ../configure-laptop/amg_config_dealii.sh
make -j8

cd ..
mkdir build
sh ../configure-laptop/dealii-config.sh
make -j8
