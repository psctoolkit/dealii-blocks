# Block Matrices and Preconditioner for Deal.II using PSCToolkit

Test of block matrices and preconditioners using Deal.II and PSCToolkit. 

To download the code, run:

```bash
git clone --recurse-submodules git@github.com:psctoolkit/dealii-blocks.git
```
This clones the examples along with the compatible commits for PSCToolkit and Deal.II.

## Configuring and installing on a Laptop with spack

The [`configure-laptop`](./configure-laptop/) folder contains example shell scripts 
to configure and compile the PSCToolkit ([PSBLAS](https://github.com/sfilippone/psblas3/) 
and [AMG4PSBLAS](https://github.com/sfilippone/amg4psblas/)) 
alongside [Deal.II](https://github.com/dealii/dealii) in a unified workflow. 

After updating the environment module names (e.g., those generated by Spack) 
in [`environment_manual.sh`](./configure-laptop/environment_manual.sh), 
run the following commands:

```bash
cd psblas3
sh ../configure-laptop/psb_config_dealii.sh
make -j8

cd ../amg4psblas
sh ../configure-laptop/amg_config_dealii.sh
make -j8

cd ..
mkdir -p build
cd build

sh ../configure-laptop/dealiiconfig.sh
cmake --build . --parallel 8

cd ..
sh configure-laptop/buld-stokes.sh
```

## Stokes block-solver example

The MPI example in [`stokes.cc`](./stokes.cc) solves the Poiseuille channel,
backward-facing step, driven cavity (three lid conventions), and colliding-flow
benchmarks with continuous Taylor--Hood elements. Select PETSc, Trilinos, or
PSBLAS at runtime, and combine diagonal or triangular block preconditioners with
independent direct applications or auxiliary Krylov solves for each block.

Build against an existing deal.II installation or build tree:

```bash
cmake -S . -B build-stokes -DDEAL_II_DIR=/path/to/dealii-build -DCMAKE_BUILD_TYPE=Release
cmake --build build-stokes -j8
./build-stokes/stokes
```

or using the provided script
```bash
sh configure-laptop/build-stokes.sh
```

```bash
# Edit the generated parameters.prm, then:
mpiexec -n 4 ./build-stokes/stokes parameters.prm
ctest --test-dir build-stokes --output-on-failure
```

Running without arguments writes a documented `parameters.prm` and exits.
An existing file is preserved. See [`README_STOKES.md`](./README_STOKES.md) for
the equations, backend options, parameter examples and description of what is 
implemented.
